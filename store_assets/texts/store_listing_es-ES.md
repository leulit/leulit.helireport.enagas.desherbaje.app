Helireport Desherbaje

## Short description (74/80)
Gestión de actividades de desherbaje en gasoductos para operadores de campo.

## Full description (0/4000)
Helireport Desherbaje es la aplicación móvil para operadores de campo, diseñada para la gestión integral de actividades de desherbaje sobre redes de gasoductos.

FUNCIONALIDADES PRINCIPALES

• Consulta de actividades asignadas: accede al listado completo de actividades de desherbaje, desbroce manual, desbroce mecánico y desratización pendientes de ejecución.

• Gestión de estados: actualiza el estado de cada actividad (propuesta, en ejecución, finalizada) directamente desde el campo.

• Captura de fotos georeferenciadas: documenta el trabajo con fotografías antes y después de la intervención, con geolocalización automática por GPS.

• Trabajo sin conexión: la aplicación funciona sin cobertura de red y sincroniza automáticamente los datos cuando se recupera la conectividad.

• Seguridad: comunicación cifrada con el backend mediante HMAC-SHA256.

REQUISITOS

• Credenciales de acceso proporcionadas por el gestor de red
• Dispositivo Android 5.0 o superior
• Cámara y GPS habilitados

Esta aplicación es de uso exclusivo para personal autorizado y sus empresas colaboradoras.
